# 🌍 EcoLend: Smart Hyper-Local Resource Sharing Platform

EcoLend is a full-stack web application designed to foster community sustainability by allowing neighbors to rent or lend underutilized items (tools, electronics, kitchenware). By integrating **Artificial Intelligence**, EcoLend simplifies item management and builds a trust-based "Circular Economy."

---

## 🛠️ Tech Stack

* **Frontend:** React.js, Tailwind CSS, Axios
* **Backend:** Node.js, Express.js
* **Database:** MySQL (Managed via MySQL Workbench)
* **Real-time:** Socket.io (for Chat)
* **AI Engine:** Groq Cloud API (Llama-3/Mixtral).

---
